# VESC 安全参数对照（电调 / 电机 / 电池）

本文是实现前的确认稿：只整理**使用中必须搞清楚、改错会伤设备或伤人**的参数，以及它们如何互相卡住。网页怎么排、哪些可写、哪些只读，等你确认后再改固件。

**结构稳定性（你的判断基本对）：**  
6.05 到 7.01，序列化**开头的限流/限压/切断/功率**字段顺序一致（电压类已是 float16）。会变的是签名、后面的 FOC/HFI/弱磁，以及 `si_battery_cells` 的偏移。6.02 电压还是 float32，串数字段在固定偏移 461。因此：**日常安全项可以按字段名稳定读写；不能按 6.02 的绝对字节偏移去改 6.05/7.01。**

## 2. 三者怎么互相限制

电调不会“只听功率”或“只听电流”。运行时同时夹：

```
可用力矩 ≈ min(
  电机相电流 l_current_max,
  电池电流映射后的 Iq（由 l_in_current_max 压下来）,
  功率 l_watt_max / 电压,
  低压切断曲线,
  温度降额,
  转速/占空比限制
)
```

近似关系（FOC，便于估数，不是精确公式）：

- 电池电流 `I_in ≈ P / V_in`
- 低转速大力矩时：相电流 `I_motor` 可以远大于 `I_in`（占空比低）
- 高转速时：`I_in` 接近 `I_motor × duty`
- 空载转速 `RPM ≈ KV × V`，电转速 `ERPM = RPM × (极数/2)`

**安全原则：每一项都取“电池、电调、电机、线材、BMS”里最弱的那个，再留余量。**  
75200 标称 150–200A 连续，**不能**当成这套 3000W 电机的工作电流。电机才是短板。

| 部件 | 能力（按公开规格） | 真正要防的事 |
| --- | --- | --- |
| 电池 | 串数 × 单芯电压；放电电流 = min(电芯 C 率×Ah, BMS) | 过放、过充（回充）、瞬时过流、压差 |
| 电调 75200 | 14–75V **或** 14–84V；50V/200A、75V/150A 连续；峰值 300–400A | MOSFET 过流/过压/过温；**无相电压滤波的板子开 Phase Filter 会炸** |
| 电机 6384 120KV | 标称约 3000W；相电流常见标 120–150A 峰值；推荐电压很多写 24–36V（偏保守） | 铜损发热、铁损（高 ERPM）、轴承/转子超速 |
| 线材 | 75200 电源约 8–10 AWG | 接头发热、压降导致欠压误报 |

## 3. 使用中真正常改、且和安全绑定的 MCCONF

按“要不要进手机网页、能不能让人随便拧”分成三档。

### A. 日常必改（建议网页可写）

这些会随**换电池串数、换包、当天想保守一点**而变。固件默认几乎等于没保护（例如 `l_watt_max` 默认 1.5MW）。

| 字段 | VESC Tool 位置 | 作用 | 配错的后果 |
| --- | --- | --- | --- |
| `si_battery_cells` | Setup / Battery | 串数；算电量%、向导填切断时用。**本身不限流** | 显示错；向导把切断填飞 |
| `l_battery_cut_start` | General → Voltage | 电压降到此开始线性减正向电流 | 太低：电芯过放；太高：提前没力 |
| `l_battery_cut_end` | 同上 | 到此正向电流为 0。必须 **高于 BMS 切断**，电调先软切 | 低于 BMS：BMS 硬断，电机突然失控 |
| `l_min_vin` | General → Advanced | 低于此 `FAULT_CODE_UNDER_VOLTAGE`，停转 | 太高：颠簸欠压就报错；太低：切不到 |
| `l_max_vin` | 同上 | 高于此 `FAULT_CODE_OVER_VOLTAGE`。要覆盖满电 + 回充尖峰 | 18S 满电 75.6V，若 max 设 75.5 **一插电就过压** |
| `l_in_current_max` | General → Current | **电池放电电流**上限（保护电池/BMS/线） | 开到 200A：电池和电机都不受功率约束 |
| `l_watt_max` | General → Current | 输出功率上限。3000W 电机应锁在额定附近 | 默认极大，等于只靠电流 |

**本工程网页已经有这 7 项。** 缺的是电机相电流、回充、转速。

### B. 强烈建议补上（日常安全，网页可写但要带默认值）

| 字段 | 作用 | 为什么必须和 A 一起 |
| --- | --- | --- |
| `l_current_max` | **电机相电流**上限（力矩） | 低速时 `I_in` 很小，只锁电池电流/功率**挡不住**把电机堵转烧组 |
| `l_current_min` | 刹车/回馈时的相电流（负值） | 刹太猛：FET 和电芯充电电流一起爆 |
| `l_in_current_min` | 回充进电池的电流（负值） | 必须 ≤ 电池允许充电电流（常远小于放电） |
| `l_watt_min` | 回充功率（负值） | 和 `l_in_current_min` 双保险 |
| `l_battery_regen_cut_start/end` | 电压高时减/禁回充 | 默认 1000/1100V = **关闭**。满电下坡会把电芯充过 4.2V |
| `l_max_erpm` / `l_min_erpm` | 电转速限制 | 18S 空载 ERPM 会明显高于 12S，铁损发热和超速是 6384 的隐藏风险 |
| `l_temp_fet_start/end` | MOSFET 85→100°C 降额到切断 | 一般保持默认即可，网页只读也行 |
| `l_temp_motor_start/end` | 电机温度同样逻辑 | **没接电机 NTC 时不要乱改类型**，否则会误报或永不保护 |

电流分层（必须同时设，且绝对值递增）：

```
|l_in_current|  <  |l_current|  <  l_abs_current_max  <  电调硬件峰值
     电池              电机相电流         瞬时故障阈值           MOSFET
```

`l_abs_current_max` 触发 `FAULT_CODE_ABS_OVER_CURRENT`。wizard 在 6.00+ 常把它改得很小，75200 官方建议再改回 **250–400A**。这个适合 **只读 + 专家改**，不要当日常滑条。

### C. 一次校准 / 硬件相关（不要放进普通网页）

改错会直接损坏 75200 或让 FOC 失步：

| 字段 | 说明 |
| --- | --- |
| `foc_motor_r / l / flux_linkage`、`foc_current_kp/ki` | 电机检测结果。用 VESC Tool 检测，不要手填 |
| `foc_sensor_mode`、Hall 表 | 无感 / Hall。6384 很多无感；有 Hall 必须检测表 |
| **`foc_phase_filter_enable`** | 官方默认 `true`。Flipsky **非 Pro V2 的 75100/75200 无相电压滤波，固件 ≥5.3 必须 false**，否则损坏 |
| `foc_fw_current_max` 弱磁 | 会把转速抬到超过 KV×V，6384 不建议网页开放 |
| `m_invert_direction` | 方向。油门校准已在 ESP 侧处理极性，电调这项保持检测时的结果 |
| APP：`timeout`、PPM/ADC `safe_start`、ramp | 失控保护。丢信号 1s 停转；安全启动要求先回中位。属 APPCONF，不是 MCCONF |

## 4. 锂电电压怎么配（3.0–4.2V 体系）

单芯常用锚点（NMC/锂电 4.20V 满电，不是磷酸铁锂）：

| 含义 | 单芯 | 电调行为 |
| --- | --- | --- |
| 满电 | 4.20 V | 应低于 `l_max_vin`，并低于回充切断终点 |
| 回充开始减 | 4.15 V | `regen_cut_start` |
| 禁止再回充 | 4.20 V | `regen_cut_end` |
| 开始减功率 | 3.50 V | `cut_start`（偏保护；想多跑可降到 3.40） |
| 正向电流为 0 | 3.30 V | `cut_end`，须 **高于 BMS** |
| 欠压故障 | 3.00 V | `min_vin`，最后兜底 |
| 过压故障 | 4.25–4.30 V | `max_vin`，给回充尖峰留余量 |

`cut_end` 必须大于 `min_vin`，`cut_start` 必须大于 `cut_end`。  
VESC 切断**只减正向电流**，不关电；BMS 才是硬断。顺序必须是：电调软切 → BMS。

## 5. 针对 75200 + 6384 120KV 3000W 的建议数

前提（**请你确认，数会跟着改**）：

1. 电池化学：锂电 4.2V 满电（不是铁锂 3.65V）。
2. 电机额定 **3000W**，相电流先按连续 **80A**、刹车 **−40A**（比电调 200A 保守得多）。
3. 电池放电电流按功率反推：`I_in ≈ 3000 / V_标称`，再向下取整。
4. 回充电流先按 **−15A**（约 0.5C@30Ah 量级；你的 Ah/BMS 充电限不同要改）。
5. 极数按 VESC 默认 **14 极（7 对极）**。若实测 Hall/厂家是 10 极，ERPM 表要重算。
6. **18S 只允许 84V 版 75200**（Pro / 标 14–84V）。壳体老款 14–75V 最高到 16S。

空载转速/ERPM（14 极）：

| 12S | 50.4 | 6048 | 42336 | 安全 |
| 14S | 58.8 | 7056 | 49392 | 贴边 |
| 16S | 67.2 | 8064 | 56448 | 铁损开始明显，建议限 ERPM |
| 18S | 75.6 | 9072 | 63504 | 超过多数 6384 标称，**不推荐除非电机明确支持** |

| 串数 | 标称 V | 3000W → I_in | 建议 `l_in_current_max` |

## 6. APPCONF（油门安全，和 MCCONF 分开）

本地固件默认：

- `APPCONF_TIMEOUT_MSEC = 1000`：控制丢失 1s 停转
- PPM/ADC `SAFE_START = true`：上电必须先回中位
- PPM ramp 正向 0.4s、负向 0.2s

ESP32 现在用 UART 读 `GET_VALUES` + 本地油门 ADC，**不改 APPCONF**。网页第一阶段不必写 APP。但若遥控直接进电调 PPM，这些和 MCCONF 限流同等重要。

控制模式：电流环（Current）比占空比（Duty）安全。Duty 会在低速把相电流顶到限幅边缘。

## 8. 请你确认的点（确认后才改代码）

1. **75200 具体型号**：75V 壳体版，还是 84V Pro / Pro V2？有没有相电压滤波（Phase Filter）？
2. **电池**：串数常用哪几档、Ah、BMS 放电/充电限流、是否 4.2V 锂电（或铁锂）？
3. **电机**：是否确认 14 极？有无 Hall / 电机温度探头？是否接受 16S/18S 的高转速？
4. **网页范围**：只做 A（现有 7 项精修），还是 A+B（补电机电流、回充、ERPM）？
5. **回充**：要不要刹车回充？若电瓶几乎不充电，建议 `i_in_min` 接近 0，避免满电顶压。
6. **功率**：继续锁 3000W，还是按串数给一个“测试 1500W / 正常 3000W”两档？

确认这 6 点后，再改 `web/index.html`（唯一页面源）和 `vesc_mcconf` 读写字段。
